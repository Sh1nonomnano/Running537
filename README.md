# 奔跑吧乌萨奇

朋友学生时代的 Java 无尽跑酷，现在也可以在浏览器里玩。

开局先选模式。经典模式里人固定在画面偏左，砖块从右边涌过来：矮的跳过去，高的蹲过去。下山模式换成顺着山坡往下冲，可以在空中翻转，也可以挥棍砸开障碍。活得越久分数越高，两种模式的最高分分开记在这台浏览器里。

原作是 [Kasaunico/Running537](https://github.com/Kasaunico/Running537) 的课程作业。这个仓库留下了原来的 Java 工程和 `Running537.jar`，另外加了一个不用构建的网页版。

## 本地怎么玩

用浏览器直接打开 `web/index.html`。图片和声音都在 `web/assets/`，打开之后不需要再联网。

如果浏览器拦住了本地页面的声音，可以用一个静态服务器：

```bash
npx --yes serve web
```

然后打开终端里给出的地址。

## 操作

开局画面选「经典模式」或「下山模式」。↑ ↓ 选择，空格、回车或直接点击开始。

经典模式：

- 跳跃：空格、↑ 或 W，躲开矮砖。
- 下蹲：按住 ↓ 或 S，躲开高砖。松开就站起来。
- 手机上按住「下蹲」，点「跳跃」。

下山模式：

- 跳跃：空格、↑ 或 W。人贴着起伏的坡面滑，跳起来才离地。
- 空中翻转：按住 ← 或 A 顺时针转，→ 或 D 逆时针转。落地时身体接近正立就能稳住，并拉开和飞鼠的距离；歪得厉害会踉跄，飞鼠会靠近。
- 挥棍：J 或 X。棍子从头顶砸到身前，朝向跟着当前的翻转走。砸中岩石或树会打碎，加速并拉开距离；在空中砸到坡面可以撑一下。
- 撞上岩石或树不会立刻结束，但会急减速、短暂失去控制，飞鼠明显靠近。飞鼠追上这一局才结束。
- 摔到坡面以下太深，或飞出界外，也会立刻结束。倒着落地本身不会立刻结束。
- 跳台会把人抛得更高，并沿坡加速。跳台和落地后都留有一小段不刷障碍的空档。滑得越快，镜头拉得越开。
- 坡上会刷出小车。碰到就开大约 5 秒：滑得更快，撞上岩石或树会把它们顶开，人不会因此结束。追赶距离仍按原来的撞击、踉跄、翻转和挥棍规则变化。
- 后面追着的飞鼠是切图，朝坡下追。
- 手机上有「顺时针」「挥棍」「逆时针」「跳跃」。翻转要按住。

两边共用：

- 暂停：Esc 或 P。
- 静音：M，或页面上的「声音」按钮。
- 游戏结束：空格或回车再来一局，Esc 或「返回选择」回到模式选择。

经典模式的分数按存活的秒数增加。游玩时左上角的数字和结算画面是同一个数。最高分用 `localStorage` 存在本机，下山另记一份。

## 网页版沿用的手感，和改掉的原作问题

重力 1800、起跳速度 -600、砖块从 -200 开始约每 8 秒加快 10，直到 -290。这些数字来自原来的 `Player`、`Block` 和 `PlayState`。

顺手改掉的四处：

- 游玩中的分数和结算分数用同一套秒数。原作画面除以 60，结算除以 100。
- 下蹲时碰撞箱变矮变小，可以从高砖下面过去。原作的下蹲盒比站立还大。
- 按住下蹲键会一直蹲着。原作不论是否按住，都只蹲 0.6 秒。
- 开局就能看见砖块从右边过来。原作要等砖块绕出屏幕才显示。

## GitHub Pages

网页在 `web/` 目录，本身就是静态文件。仓库里的 `.github/workflows/pages.yml` 会把这个目录发布出去。

1. 把改动合并进默认分支（本仓库是 `main`）。
2. 打开仓库的 Settings → Pages。
3. Build and deployment 的 Source 选 **GitHub Actions**。
4. 之后推到 `main` 会自动部署。

站点地址一般是 `https://<用户名>.github.io/Running537/`。

## 原来的 Java 版

还在 `Running537/SimpleJavaGDF`，可执行包是根目录的 `Running537.jar`。网页版没有删这些文件。

```bash
java -jar Running537.jar
```

它需要桌面环境，也依赖较旧的 Java（声音用的是 Applet）。这是存档；网页版不靠它运行。
